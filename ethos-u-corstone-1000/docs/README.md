# Arm® Ethos™-U and Arm® Corstone™-1000 Documentation

This directory contains workflow documentation for the Arm® Corstone™-1000
reference package direct-drive examples for Arm® Ethos™-U NPUs.

Start here:

* [BUILDING.md](BUILDING.md): native and Corstone-1000 AArch64 builds.

* [PACKAGING.md](PACKAGING.md): creating FAT MMC images for the FVP.

* [DEPLOYING.md](DEPLOYING.md): launching the FVP and running examples on the
  target.

* [DEVELOPMENT.md](DEVELOPMENT.md): local development checks, including
  clang-tidy.
